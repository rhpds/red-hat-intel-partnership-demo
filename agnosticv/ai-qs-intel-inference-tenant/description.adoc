
Deploys the Intel-Red Hat AI Inference Platform on a shared base cluster via the OpenShift Sandbox API. Demonstrates dual-path inference routing across Intel Xeon 6 (CPU/OpenVINO) and Gaudi 3 (GPU) backends via the MAAS LiteLLM proxy.

== What Gets Deployed

* *Inference Gateway* -- FastAPI router with hardware-aware routing engine
* *Dashboard* -- React/PatternFly cockpit with workload demos and visualizations
* *PostgreSQL* -- Persistence for request logging, tenant management, and audit
* *LiteLLM Virtual Key* -- Scoped API key for MAAS model access

== Models Available

=== CPU Path (Xeon 6 + OpenVINO)
* granite-2b-cpu (26 t/s)
* phi3-mini-cpu (30 t/s)
* qwen25-3b-cpu (24 t/s)
* nomic-embed-text-v1-5 (embeddings)

=== GPU Path (Gaudi 3)
* deepseek-r1-distill-qwen-14b (55 t/s)
* llama-scout-17b (60 t/s)
* microsoft-phi-4 (47 t/s)
* qwen3-14b (37 t/s)


Base OpenShift Infra Cluster for Intel Inference Quickstart tenants.

This catalog item deploys shared platform services on top of an OpenShift cluster, preparing it to host Intel Inference Quickstart tenant environments via the OpenShift Sandbox API.

== What Gets Deployed

* *Keycloak SSO* -- OpenShift authentication with admin and per-user accounts
* *ArgoCD (OpenShift GitOps)* -- GitOps operator for tenant workload delivery
* *OpenShift AI 3* -- Dashboard, pipelines, workbenches, model serving

== Design

This catalog item is designed to be registered with the OpenShift Sandbox API.
Individual Intel Inference tenants are provisioned on top of this base cluster.

The Intel Inference Platform routes AI workloads across Intel Xeon 6 (CPU/OpenVINO) and Gaudi 3 (GPU) backends via the MAAS LiteLLM proxy, demonstrating hardware-aware dual-path inference routing.

== Requirements

Deploys on top of an OpenShift 4.20+ cluster with CNV (Container Native Virtualization) installed.
